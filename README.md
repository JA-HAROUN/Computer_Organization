# 🚀 Computer Organization Labs — Arduino & Assembly

Welcome to this hands-on lab repository for **Computer Organization**.  
It brings together practical Arduino experiments and low-level problem solving to help bridge hardware concepts with real implementation.

## 🌟 Project Overview

This repository collects lab submissions, reference materials, and demonstrations focused on:
- Microcontroller fundamentals using Arduino
- Digital I/O, timing, and control logic
- Assembly-style thinking through step-by-step hardware interaction

## ✅ Highlights

- Clean lab-by-lab organization (`#1` to `#5`, plus `HeatLab`)
- Real project artifacts (`.ino` sketches, videos, PDFs, and screenshots)
- Progressive learning flow from foundational to more advanced tasks

## 🧪 Lab Focus / Repository Structure

- `#1` – Introductory Arduino lab work
- `#2` – Traffic light / control-sequence implementation
- `#3` – Multi-problem Arduino exercises
- `#4` – Additional lab practice and documentation
- `#5` – Extended sketches, Visual Studio Arduino project files, and media
- `HeatLab` – Dedicated temperature/heat-related lab exercise

## 🤝 Welcome

Whether you're reviewing past labs or starting fresh, this repo is organized to make exploration easy.  
Feel free to browse each folder, run the sketches, and build on the ideas for your own projects.
